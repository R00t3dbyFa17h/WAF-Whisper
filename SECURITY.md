# Security Policy

## Intended use

WAF Whisper sends attack-shaped traffic and is intended **only** for authorized
engagements — bug-bounty programs with assets in scope, penetration tests with
a signed statement of work, and systems you own. Using it against targets
without explicit permission may be illegal.

## Reporting a vulnerability

If you find a security issue **in WAF Whisper itself** (for example, unsafe
handling of a target response, or an injection via a crafted argument), please
report it privately rather than opening a public issue:

- Open a [GitHub Security Advisory](https://github.com/R00t3dbyFa17h/WAF-Whisper/security/advisories/new), or
- Contact the maintainer **R00t3dbyFa17h** via GitHub.

Please include a description, affected version, and a minimal reproduction.
You will receive an acknowledgement, and a fix or mitigation will be
coordinated before public disclosure.

## Supported versions

The latest released version on the `main` branch is supported.
